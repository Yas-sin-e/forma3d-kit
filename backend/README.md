# Backend

Ce dossier accueillera l’API FastAPI, sa configuration, les modèles SQLAlchemy et les tests backend à partir de l’étape 4.

À l’étape 2, ce fichier décrit le rôle du dossier ; aucun serveur ni code applicatif n’y est encore présent. Les commandes de lancement et de test seront ajoutées avec l’implémentation du backend.

Les secrets restent dans un fichier local .env ignoré par Git. Le stockage des images et des modèles est destiné à rester local au MVP, derrière une interface remplaçable.
